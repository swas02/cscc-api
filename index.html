Country-Level Social Cost of Carbon API

A fast, zero-dependency static data API that compiles 247,860 scenarios (~2.5 lakh rows) into lightweight per-country binary files (~22.8 KB each) for instant client-side querying.

Data Ownership & Attribution Disclaimer

The original authors and owners of the underlying CSV dataset are country-level-scc (published in Nature Climate Change by Ricke et al., 2018).

The maintainers of this repository are NOT the owners or creators of the CSV data. This project provides solely the static API release format, compression tooling, and the client JavaScript library to query the published dataset efficiently in web browsers and programmatic environments.

Integration Quickstart

1. Include CDN Client Script

Add the lightweight client script to your HTML page (zero external dependencies): 

<script src="https://swas02.github.io/cscc-api/v1/index.js"></script>
2. Query Dataset in Browser

Query scenarios asynchronously with automatic caching and sub-millisecond in-memory lookups: 

<script>
  DataAPI.ready().then(async (meta) => {
    console.log(`CSCC API Ready (${meta.countries} countries loaded)`);

    // 1. Filtered scenario search for India (IND):
    const scenarios = await DataAPI.getData('IND', {
      ssp: 2,     // SSP2
      rcp: 4.5,   // RCP 4.5
      dr: 3       // 3% constant discount rate
    });
    console.log(`Found ${scenarios.length} scenarios:`, scenarios[0]);

    // 2. Exact single-scenario point lookup for USA:
    const point = await DataAPI.get('USA', {
      run: 'bhm_sr',
      dmgfuncpar: 'bootstrap',
      climate: 'expected',
      ssp: 2,
      rcp: 4.5,
      dr: 3
    });
    console.log(`USA Median CSCC: $${point.p50} / tCO2 (Range: $${point.p16_7} - $${point.p83_3})`);
  });
</script>
1. Install Package

Install directly into any Node.js or Bun project without manually cloning: 

npm install github:swas02/cscc-local#v1.0.0
2. Query Dataset (100% Offline)

Execute queries in CommonJS, ES Modules, or Bun with sub-millisecond local speed: 

const cscc = require('cscc-local'); // or import cscc from 'cscc-local'

async function main() {
  // Filter scenarios for India (IND):
  const rows = await cscc.getData('IND', { ssp: 2, rcp: 4.5, dr: 3 });
  console.log('Results:', rows[0]);

  // Synchronous point query (zero await):
  const point = cscc.getSync('USA', {
    run: 'bhm_sr',
    dmgfuncpar: 'bootstrap',
    climate: 'expected',
    ssp: 2,
    rcp: 4.5,
    dr: 3
  });
  console.log('USA Median:', point.p50);
}
main();

API Methods & Schema Reference

Both the browser client (DataAPI) and the Node.js/Bun client (cscc-local) share the same uniform API methods, parameters, and response structures.

Client Methods
Method Signature Description
ready()
Sync: readySync()		 Promise<Meta> Initializes dataset dictionaries, dimension layouts, and row schema.
getData(iso3, filter?)
Sync: getDataSync()		 Promise<Row[]> Returns matching scenario rows for an ISO3 country. Accepts filter object like { ssp: 2, rcp: 4.5, dr: 3 }.
get(iso3, key)
Sync: getSync()		 Promise<Row | null> Performs an exact scenario point query matching all dimensions (instant O(1) in-memory array index).
countries()
Sync: countriesSync()		 Promise<string[]> Returns all 170 available ISO3 country codes in alphabetical order.
options(filter?)
Sync: optionsSync()		 Promise<Options> Returns dynamically valid dimension values given an active filter.
prefetch(iso3)
Sync: prefetchSync()		 Promise<void> Pre-fetches one or multiple countries (e.g. ['USA', 'IND']) into memory cache.
clearCache() void Flushes all cached binary buffers from RAM.
Returned Row Schema
Field Type Description / Example
p50 number Median Social Cost of Carbon in USD / tCO2 (e.g. $139.41)
p16_7 / p83_3 number | null 16.7th and 83.3th percentile confidence range (66.7% credible interval, e.g. $48.42 - $149.47)
n number Monte Carlo simulation sample size (e.g. 1000 runs)
ssp string Shared Socioeconomic Pathway (SSP1 through SSP5)
rcp string Representative Concentration Pathway (rcp45, rcp60, rcp85)
dr number | null Constant discount rate (e.g. 3 or 5 percent)
prtp / eta number | null Ramsey discounting parameters: pure rate of time preference / elasticity of marginal utility
run / climate / dmgfuncpar string Model specifications: damage specification, climate uncertainty, and econometric parameters
