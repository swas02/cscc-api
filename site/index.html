Country-Level Social Cost of Carbon API

A fast, zero-dependency static data API that compiles 247,860 scenarios (~2.5 lakh rows) into lightweight per-country binary files (~22.8 KB each) for instant client-side querying.

Try Interactive Query Get Integration Code
Data Ownership & Attribution Disclaimer

The original authors and owners of the underlying CSV dataset are country-level-scc (published in Nature Climate Change by Ricke et al., 2018).

The maintainers of this repository are NOT the owners or creators of the CSV data. This project provides solely the static API release format, compression tooling, and the client JavaScript library to query the published dataset efficiently in web browsers and programmatic environments.

Quickstart & Client Integration 

<!-- Load the zero-dependency client from GitHub Pages or CDN -->
<script src="https://<username>.github.io/<repo>/v1/index.js"></script>

<script>
  // Automatically resolves baseUrl relative to the script tag location
  DataAPI.ready().then(async () => {
    // 1. Fetch filtered scenario data for a country
    const results = await DataAPI.getData('IND', {
      ssp: 2,
      rcp: 4.5,
      dr: 3
    });
    console.log('Returned rows:', results);

    // 2. Fetch an exact single scenario point
    const single = await DataAPI.get('USA', {
      run: 'bhm_sr',
      dmgfuncpar: 'bootstrap',
      climate: 'expected',
      ssp: 'SSP2',
      rcp: 'rcp45',
      dr: 3
    });
    console.log('USA Median CSCC:', single.p50);
  });
</script>
const DataAPI = require('./src/index.js'); // or from npm package

// In Node.js, specify the base static URL
DataAPI.configure({
  baseUrl: 'https://<username>.github.io/<repo>/v1/'
});

async function run() {
  await DataAPI.ready();

  // Query country data
  const data = await DataAPI.getData('USA', { ssp: 2, rcp: 4.5, dr: 3 });
  console.log(`Loaded ${data.length} records for USA:`, data[0]);
}

run();
